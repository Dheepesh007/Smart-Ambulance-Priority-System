# Smart Ambulance Priority System 🚑🚦

This project gives automatic traffic signal priority to ambulances by detecting siren activation and distance.

## Objective
- Reduce ambulance delay at traffic signals
- Automatically control traffic lights
- Avoid manual switching by driver

## Technologies Used
- Arduino UNO
- Ultrasonic Sensor
- LEDs (Traffic lights)
- Tinkercad Simulation
- GitHub for version control

## Project Structure
- code/ : Arduino source code
- report/ : Project report PDF
- circuit-design/ : Circuit diagrams & Tinkercad screenshots
- images/ : System images
